Client setup (Android)

  1. Install the official strongSwan VPN Client from Google Play.
  2. Download the CA certificate: {{ pki.DOWNLOAD_NAME }} (requires panel login). This is the public CA certificate used to verify the VPN server's identity — it contains no secrets and is the same for all users of this server.
  3. Android Settings → Encryption & credentials → Install a certificate → CA certificate → pick the downloaded file.
  4. In the strongSwan app: Add profile
    • Server: {{ env.public_ip or 'YOUR_SERVER_IP' }}
    • Type: IKEv2 EAP (Username/Password)
    • Username / password: as provided by the admin
    • CA certificate: select the Aurora CA you installed (aurora-manager-ca.pem)
  5. Connect. First connection may take a few seconds.

Never share your credentials. Admins never see existing passwords.
